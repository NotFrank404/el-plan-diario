      Llave de conexión a TMDB (API Key)

      Introduce tu API Key gratuita de TMDB para buscar películas reales en español.

      ¿Aún no tienes tu API Key gratuita? Mira cómo conseguirla en 2 minutos
      1. Entra en themoviedb.org y crea una cuenta gratuita (y confirma tu correo).
      2. Abre tu perfil (arriba a la derecha) ➔ Ajustes (Settings) ➔ sección API en el menú lateral (enlace directo a Ajustes de API).
      3. Si es tu primera vez, pulsa en Crear / Request an API Key, elige la opción Developer, acepta los términos y rellena los datos básicos diciendo que es para un "Proyecto personal para aprender desarrollo web".
      4. Copia el código llamado Clave de la API (API Key v3) o el Token de acceso de lectura y pégalo en la cajita de arriba. Se guardará solo en tu navegador.
